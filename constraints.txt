# Reproducible dependency resolution for CI and deployment.
#
# Generated with Python 3.11 (the version CI uses) from a clean install of
# `pip install -e ".[dev]"`, then frozen:
#
#     python -m venv .venv && . .venv/bin/activate
#     pip install -e ".[dev]"
#     pip freeze | grep -viE '^-e|betmaxxing' | sort > constraints.txt
#
# Install against it with:
#
#     pip install -e ".[dev]" -c constraints.txt
#
# `pyproject.toml` keeps loose lower bounds so the package stays installable
# in other contexts; this file is what makes a CI run reproducible. Regenerate
# it deliberately when upgrading, never as a side effect.
#
# Starlette >= 1.3 prefers `httpx2` for its TestClient and emits a
# StarletteDeprecationWarning when it has to fall back to `httpx` 0.x. The
# earlier tranche silenced that warning with a filter; the filter is gone and
# `httpx2` is pinned here instead, so the warning no longer occurs at all and
# `pytest -W error` passes without exceptions. The application's own provider
# client still uses `httpx`: the two distributions have different import names
# and coexist. `httpcore2` and `truststore` are httpx2's dependencies.
#
# `psycopg` is pinned here too, not just in the optional extra: CI runs the
# concurrency suite against a real PostgreSQL, because SQLite serialises every
# writer and therefore cannot tell an atomic algorithm from a lucky one.
